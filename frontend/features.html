The storyline

One workbench, from first baseline to fine-tuned model

Every research program starts small — a dataset, a question, a first fit. This workbench is where that journey plays out end-to-end, on your own hardware. Open a session, drop in data, and ask Fox for a baseline regression; it runs the code on a persistent kernel, records the run with its exact code, environment, model and metrics, and a background reviewer suggests the next move. Push further with parameter sweeps, improve loops and background campaigns until you hit your target — then keep climbing, through model benchmarks and literature grounding, all the way to fine-tuning an LLM on your own data and proving the adapter beats the base model. Every step is tracked, verifiable, and audit-able. And nothing leaves your machine unless you explicitly approve it.

🎯 What is it used for?

Agentic, chat-driven data science and machine learning — with every run captured and comparable.

  • Run experiments by talking: load data, fit models, tune parameters, report metrics.
  • Track everything as experiments with goal metrics, targets, and leaderboards.
  • Improve autonomously via reviewer-driven loops, sweeps, campaigns and benchmarks.
  • Fine-tune LLMs (LoRA/QLoRA) on local GPUs and verify base-vs-adapter.
  • Stay private — local models, local kernels, your data never leaves home.

🏁 What it accomplishes

It turns a conversation into a reproducible research program and closes the loop between running, reviewing, and learning.

  • A run is a record — code, env, metrics, model, integrity hash, git commit.
  • A result becomes a learning — measured outcomes feed back into the agent's context.
  • A hypothesis becomes a verdict — regression checks say ✓ improved / ✗ no gain.
  • A project becomes a report — generated write-up, next-research agenda, zip export.
  • A model becomes an adapter — trained, exported, and validated against its base.

🚀 What it is capable of

A full local AI research stack in one browser tab, with an open MCP toolbox.

  • Agent + kernels — chat-driven Python/R, Jupyter notebooks, in-browser VS Code.
  • Autonomy — improve loops, parallel parameter sweeps, background campaigns, benchmarks.
  • MCP servers — science, privacy, robustness, arXiv replication, GraphRAG, EDA — plus dk-lora (training) and ft-validate (RAG verification).
  • Live finetune monitoring — pipeline card + streaming debug log in the chat.
  • Trust — tamper-evident audit trail, run restore, integrity verification.

Trust

Audit trail sample

Every tool call, permission decision, network access and filesystem touch is captured, redacted, and hash-chained (SHA-256, tamper-evident). A representative sample from the live trail:

{
  "event_id": "01KZGYCCBPFD6W1JXDS03P0R0T",
  "source": "coordinator",
  "tool_name": "save_artifact",
  "severity": "info",
  "duration_ms": 0.48,
  "network": false,
  "filesystem": true,
  "data_access": true
}

Each event is redacted (no secrets), references the previous event's hash, and can be verified via verify_chain; each run carries an integrity hash and links to its audit trace. The 🛡 Audit view adds per-agent history, permission-drift, deviation flags, and a searchable timeline.
